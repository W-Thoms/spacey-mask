# spacey-mask
# IBM Data Science Capstone Project

The overarching business question: since SpaceX's reusable boosters make launches cheaper, could a competitor ("Space Y") replicate that advantage? The project answers this by collecting, cleaning, exploring, visualizing, and modeling SpaceX launch data end-to-end.

## Project Overview

A full data science pipeline was built covering data collection (API + web scraping), data wrangling, exploratory analysis (SQL + visualization), interactive geospatial and dashboard visual analytics, and machine learning classification to predict landing outcomes — culminating in a business-facing findings presentation and recommendations.


The .ipynb files show the process for each of these steps and how they were completed. 

See *Space Y Project Findings Powerpoint Presentation.pdf* for the overall findings from each step of the process. Included in the presentation are screenshots from dashboards, charts, sql queries and maps.
